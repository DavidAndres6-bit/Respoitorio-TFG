+ El script importa los módulos necesarios: os para rutas y archivos, re para expresiones regulares, requests para descargar contenido web, zipfile para descomprimir archivos ZIP y BeautifulSoup para procesar HTML. 
+ Se define una carpeta temporal (RUTA_TEMP) donde se guardarán los archivos ZIP descargados. Esta ruta se adapta según el entorno (PythonAnywhere o PC local).
+ Se define la URL oficial de la DGT donde se publica mensualmente el listado del parque de vehículos.
+ Se define un patrón de URL (PATRON_ZIP) que permite construir la dirección exacta del ZIP final sustituyendo la fecha detectada.

Función obtener_ultima_fecha()
 - Descarga el HTML de la página de la DGT usando requests.get() y comprueba errores con raise_for_status().
 - Procesa el HTML con BeautifulSoup para extraer todo el texto visible de la página.
 - Utiliza una expresión regular (20\d{4}) para encontrar todas las fechas en formato YYYYMM.
 - Si no se encuentra ninguna fecha, lanza una excepción controlada.
 - Se obtiene la fecha más reciente usando max(fechas) (lexicográficamente correcto con YYYYMM).

Función descargar_zip(fecha)
 - Construye la URL final del ZIP sustituyendo {fecha} en el patrón definido.
 - Genera el nombre del archivo ZIP y la ruta completa donde se guardará en la carpeta temporal.
 - Descarga el ZIP con requests.get() y comprueba que la descarga no falle con raise_for_status().
 - Guarda el contenido en disco en modo binario (wb).
 - Imprime información de progreso para que sepas en qué punto estás.

Función descomprimir_zip(ruta_zip)
 - Abre el ZIP con zipfile.ZipFile.
 - Itera sobre todos los archivos contenidos (zip_ref.infolist()).
 - Sanitiza los nombres de los archivos reemplazando caracteres inválidos (<>:"/\|?* y caracteres de control) por _.
 - Extrae los archivos en la misma carpeta temporal (RUTA_TEMP).
 - Imprime un mensaje para cada archivo extraído.
 - Permite trabajar de forma segura en Windows y Linux (PythonAnywhere).

Función main()
 - Obtiene la fecha más reciente, descarga el ZIP y lo descomprime.
 - Imprime mensajes de progreso para seguimiento completo del proceso.

Bloque if __name__ == "__main__":
 - Garantiza que main() solo se ejecute si el script se ejecuta directamente, evitando ejecución automática si otro script lo importa.

Ventajas de esta estructura
 - Funciona de forma independiente o integrada dentro de un pipeline mayor.
 - Permite descargar y descomprimir ZIPs de la DGT de forma automática y segura.
 - Incluye mensajes de información ([INFO]) para depuración y seguimiento.
 - Prepara el terreno para pasos posteriores: filtrar archivos .txt, convertir a CSV y cargar en base de datos.

PROBLEMAS (PythonAnywhere)
 - El script funciona correctamente en local.
 - En PythonAnywhere Free, se producen errores del tipo ProxyError y 403 Forbidden porque todas las conexiones HTTP/HTTPS pasan por un proxy compartido.
 - La DGT bloquea explícitamente el acceso desde estos proxies.
 - La solución: usar un plan de pago, descargar localmente y subir manualmente el ZIP, o usar otro servidor sin restricciones de red.

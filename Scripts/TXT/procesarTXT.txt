- El script importa los módulos necesarios:
	+ os para trabajar con rutas y carpetas del sistema.
	+ zipfile para abrir y manipular archivos comprimidos en formato ZIP.
	+ Se importa la función obtener_ultima_fecha() desde descarga.py para detectar automáticamente el ZIP más reciente descargado.
- Se define una carpeta temporal (RUTA_TEMP) donde se encuentran los archivos ZIP descargados y donde se extraerán los archivos TXT.
- Se define una lista de provincias (PROVINCIAS_CYL) correspondientes a Castilla y León, que son los archivos que nos interesa extraer del ZIP.
- Se incluyen variantes con y sin tilde para algunas provincias (por ejemplo ÁVILA / AVILA o LEÓN / LEON) porque los nombres pueden variar en distintos archivos ZIP publicados por la DGT.
- Se genera una segunda lista (PROVINCIAS_CYL_UPPER) convirtiendo todos los valores a mayúsculas para facilitar las comparaciones de forma insensible a mayúsculas/minúsculas.

Función descomprimir_zip(ruta_zip)
- Abre el archivo ZIP utilizando zipfile.ZipFile.
- Recorre todos los archivos contenidos dentro del ZIP mediante zip_ref.infolist().
- Convierte el nombre de cada archivo a mayúsculas para realizar comparaciones consistentes.
- Comprueba si el nombre del archivo contiene alguna de las provincias definidas en PROVINCIAS_CYL_UPPER.
- Si el archivo pertenece a una provincia de Castilla y León:
	+ Se imprime un mensaje indicando qué archivo se está extrayendo.
	+ Se extrae el archivo en la carpeta temporal (RUTA_TEMP).
- Se utiliza una estructura set (extraidos) para evitar extraer el mismo archivo más de una vez.
- Control de memoria
	+ El script no extrae todos los archivos del ZIP, solo los necesarios.
	+ Esto reduce significativamente el uso de memoria y almacenamiento.
	+ Esta optimización es especialmente importante en entornos como PythonAnywhere, donde los recursos son limitados.

Eliminación del archivo ZIP
- Una vez finalizada la extracción:
- El script comprueba si el archivo ZIP todavía existe utilizando os.path.exists().
- Si existe, lo elimina mediante os.remove() para liberar espacio en disco.
- Si no existe, se muestra un mensaje informativo.
- Esto permite conservar únicamente los TXT necesarios para el análisis posterior.

Función main()
- Centraliza el flujo principal del script.
- Ejecuta las siguientes operaciones:
- Detecta la fecha más reciente publicada en la web de la DGT mediante obtener_ultima_fecha().
- Construye el nombre del archivo ZIP correspondiente a esa fecha.
- Genera la ruta completa del archivo dentro de la carpeta temporal.
- Llama a la función descomprimir_zip() para extraer únicamente los archivos TXT de Castilla y León.
- Elimina el archivo ZIP una vez finalizado el proceso.

Bloque if __name__ == "__main__":
- Garantiza que la función main() solo se ejecute cuando el script se ejecuta directamente.
- Permite que las funciones del script puedan ser importadas desde otros módulos sin ejecutarse automáticamente.
- Facilita la integración del script dentro de un pipeline mayor de procesamiento de datos.

Ventajas de esta estructura
- El script tiene una responsabilidad clara: procesar el ZIP descargado y extraer solo los TXT necesarios.
- Reduce el uso de memoria y almacenamiento extrayendo únicamente los archivos relevantes.
- Permite automatizar el proceso mensual sin modificar el código manualmente.
- Es compatible con entornos Windows, Linux y PythonAnywhere.
- Incluye mensajes informativos que permiten seguir el progreso del proceso.
